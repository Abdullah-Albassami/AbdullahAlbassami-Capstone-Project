# HelpDesk Pro

**IT support ticket management for small and medium-sized businesses**

HelpDesk Pro is a Django application for submitting, assigning, tracking and resolving internal IT support requests. It has separate Employee, Technician and IT Admin roles, category management, search and workload reporting.
